# 补充人物动画提示词概要

生成模式：内置 ImageGen，透明背景。

统一约束：保持与原角色完全相同的深棕乱发、棕色眼睛、芥黄色围巾、蓝绿色长外套、深色短裤、米白袜、棕色靴和棕色斜挎包；保持原有二维动漫小比例、带轻微像素边缘的绘制方式；水平排列、等距、完整全身、透明背景、无文字、无编号、无网格、无水印。

- Idle Front / Side / Back：4 帧轻微呼吸循环，脚底固定，只改变肩部、胸口、衣摆、发梢和围巾。
- Interact Front / Side / Back：6 帧通用设备操作，从待机到观察、抬手、伸手按压或调节、保持、收手；不绘制具体设备或工具。
- Success Front：6 帧克制的成功反应，眼神明亮、轻微微笑、小幅握拳、放松。
- Failure Front：6 帧温和的操作失误反应，轻微惊讶、垂肩思考、挠头、深呼吸后恢复专注。
