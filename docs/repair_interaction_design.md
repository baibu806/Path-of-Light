# 小检修交互对照

每一步只显示对应的检修设备画面，不叠加外层说明框。青色圆环是当前可操作部位，金色圆环是待取的工具或零件，绿色勾表示已完成。顺序错误或放错安装位会短暂显示针对当前对象的纠错文字，并计入本层失误数；参数和方位未到安全区时允许继续调整，不扣分。玩家停顿 7 秒后，才显示一句简短、温和的提示：有空白铭牌的地基、电路与灯塔检修图直接写在图内铭牌上，其他没有安全空白区的画面仍显示在设备下方，避免遮住可操作部件；一旦继续操作，提示即消失。

| 楼层 | 步骤 | 画面上的操作 | 完成判定 |
| --- | --- | --- | --- |
| 地基 | 清盐霜 | 从画面刮刀拖向三处盐霜 | 三处按序清理 |
| 地基 | 空鼓检查 | 点选石料、接缝、空鼓、补位 | 四处依次确认 |

| 管道 | 泵压测试 | 上拖阀门和压力标记 | 两项进入安全区后启动 |

| 主灯 | 启动 | 点选断路器、预热、主灯 | 启动顺序正确 |

参数和方位进入安全区时自动确认，无须另按锁定按钮。点击右上角红色关闭图标或按 Esc 可返回场景；取消检修不推进任务，再进入时从该检修步骤重新开始。楼层全部完成后，才触发整层修复过渡和徽章结算。
